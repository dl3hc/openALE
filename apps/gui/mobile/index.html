Getting Started
Quick Start

openALE is a mobile console for MIL-STD-188-141B 2nd-Generation Automatic Link Establishment (2G ALE), controlling a radio via Hamlib/CAT.

Fastest path: on first run, open the ☰ More menu and look for the Setup Wizard — a 4-step flow (Callsign → Audio Devices → Radio/CAT → Load Channels) that does everything below for you, with Skip available at every step. The steps here cover the same ground manually, and are the reference to come back to later.
  1. Set your station callsign.

    Settings → Identity → add a Self Address. This is your ALE callsign, shown as SELF in the header.

  2. Connect your radio.

    Settings → Radio / CAT → pick your Hamlib rig model, enter host/port or serial settings, then tap Connect.

  3. Pick your audio devices.

    Settings → Audio (under Advanced → Modem/System) → select RX Input and TX Output, then run the level test.

  4. Load a channel plan.

    Settings → Files → Load a .ale file. The wizard's default is nets/hflink_usa.ale; presets also exist for EUR/UK/JA/AUS regions.

  5. Review Channels and Nets.

    Settings → Channels / Nets — both are in the "Essential" group, always visible without expanding Advanced.

  6. Save & Apply, then Scan.

    Tap Save & Apply, close Settings, then toggle Scan in the header. See Files for what actually persists across restarts.

Unfamiliar terms like SELF, LQA or Sounding? See the Glossary tab.

Glossary

Plain-language definitions for the ALE and radio jargon used throughout openALE.

SELF
Your station's own ALE address (callsign), shown in the header.
Net
A named group of channels sharing one dwell/sounding schedule and calling list.
Channel
One RX/TX frequency pair (with mode) that ALE can scan, sound and call on.
Scanning
Continuously stepping through a channel list listening for calls addressed to you or AllCall.
Sounding
A station periodically transmitting an unaddressed test signal so others can measure link quality to it.
LQA (Link Quality Analysis)
The database of measured link quality between stations/channels, used to auto-pick the best channel for a call.
SINAD
Signal to Noise-And-Distortion ratio in dB — a raw measurement behind an LQA score. Higher is better.
BER
Bit Error Rate from the ALE waveform's redundant encoding — the other raw LQA measurement. Lower is better.
Handshake
The call/response/acknowledge exchange that establishes a link between two stations.
AMD
Automatic Message Display — a short free-text message sent over ALE, the closest thing to a text message.
AllCall
The reserved broadcast address every ALE station listens to, for calls to "anyone listening."
Hamlib / CAT
The library/protocol openALE uses to remote-control your radio's frequency, mode and PTT.
PTT Lead / Tail
Extra keyed time before/after audio, to absorb relay or amplifier switching latency.
Grid Locator (Maidenhead)
A compact geographic coordinate code (e.g. EM12) usable in place of decimal lat/lon.
Relink
Automatically moving an established call to a better-scoring channel when quality drops.
Enhanced Frequency-Select
Using LQA scores instead of plain scan order to choose which channel to call on.
LBT (Listen Before Transmit)
A busy-channel check right before transmitting, to avoid keying over another station.

CAT / Rig Traffic trace

Test Connection vs Connect

Test Connection only checks reachability. Connect takes and holds control of the radio — required before scanning/calling.

ALE
Timing

Protocol timing, mostly aligned to MIL-STD-188-141B defaults. Only change these if you understand the handshake state machine.

Call / Handshake Timeout

How long to wait for a response, and the max time for the full handshake, before giving up.

Link Idle Timeout

How long an established link may sit idle before being torn down automatically.

AMD Wait

Gap for TX/RX switching, and the time budget given to an antenna tuner during a handshake.

Extra keyed time before/after audio. Keep Lead low — it eats into the ~650 ms minimum protocol reply window. SDR/virtual-audio-cable setups typically need a higher Tail (150–250 ms) since that latency is invisible to openALE; raising Tail is always safe.

Policy

Controls how incoming calls are accepted.

Auto-Accept

On: matching calls link automatically. Off: every call needs manual acceptance within the timeout.

Accept Any Call / AllCall / AMD

Independently allow calls from unknown stations, broadcast AllCall, and inbound AMD without a linked session first.

Link Policy (Outbound Defaults)
Individual / Group / ALLCALL

Default TIS/TWAS conclusion for a fresh AMD send of each type — TIS keeps the link open, TWAS delivers and concludes. Always overridable per send via the compose-row Link checkbox.

ALE
LQA

The measured-quality database used to auto-pick the best channel for a call.

Record LQA

Every sounding/handshake updates the database with a fresh score.

Auto-Relink + threshold

Moves an established call to a better channel once quality drops below the threshold.

Enhanced Frequency-Select

Uses LQA scores rather than plain scan order to choose a calling channel.

LQA Age Limit

Scores older than this are treated as stale and excluded from selection.

Table (FROM/TO/Score/TIS/TWAS)

TIS ("this is") / TWAS ("that was") show the latest vs previous measurement. Refresh re-pulls from the bridge; Clear wipes the database.

Audio Devices

Two distinct audio interfaces, configured on two potentially different machines: the Modem Audio Interface is the transceiver's own sound-card link, set up on whichever machine runs the controller/bridge. The Operator Audio Interface is this browser's own mic/speaker, saved locally and never sent to the controller.

Modem Audio Interface
RX Input / TX Output

The interface connected to your radio's receive/transmit audio — typically a USB sound card, not the phone/laptop's built-in mic/speaker.

Level meter / TX Volume

Connect Audio / Level Test / Refresh List

Open the selected devices, run a local level check, or re-scan for newly attached devices.

Operator Audio Interface
Microphone / Speaker

Voice Passthrough — Armed

Mic Test

Local playback to confirm mic levels before going on the air.

Channel Monitor

A "listen in" toggle in the header streams the transceiver's RX audio here regardless of link state — for listening to the channel while scanning or idle.

Notifications — Ring / Chime / Volume

Optional locally-synthesized tones through the selected speaker: a ring for an incoming call, a chime when a message arrives.

Modem / System
FEC / Sync

Golay(24,12) forward-error-correction voting used to recover ALE words from noisy audio.

Correction mode (3/4, 2/5, 1/6, 0/7)

How many of the 7 redundant repeats may disagree before a word is still accepted. More tolerance decodes weaker signals but risks wrong-word acceptance.

Min Unanimous Votes

Of 49 possible bit votes per word, the minimum agreement needed to trust a bit outright.

Adaptive FEC

Adjusts correction strictness automatically based on recent channel conditions.

Modem / System
Logging

Controls log verbosity, on disk and in the ALE Log panel.

Log Level

Raise when diagnosing a problem; keep low for normal operation.

Log File

Path logs are written to, in addition to the on-screen panel.

RX Debug Output

Additional raw demodulator diagnostics for troubleshooting decode issues.

Files

LQA Database (lqa.bin)

Troubleshooting

Common first-run and operational issues.

"Bridge Offline" flashes briefly on load

Normal WebSocket reconnect — should clear within a few seconds if openALE is running.

Radio / Scan controls greyed out

Radio/CAT isn't connected — go to Settings → Radio/CAT and tap Connect (Test Connection alone doesn't take control).

No stations ever appear in Heard Stations

Check audio is flowing (Settings → Audio level test), a net/channel is selected, and Scan is running.

Channels/Nets gone after restart

Expected — see Files. Load your .ale file explicitly each session.

Test Channel fails on every channel

The peer must be reachable on each tested frequency — real propagation and time-of-day affect results.
