Delay after PTT key-up before audio transmits — covers CAT/CI-V latency. Default 10 ms covers typical SDR/CAT hardware; without it the first word (your own full callsign) can be clipped before the radio has actually keyed, confusing the other station. The protocol's handshake timing windows are only tens of ms wide, so values much above ~10 ms can silently break handshaking with other stations entirely — only raise it for demonstrably slower CAT/PTT hardware.
